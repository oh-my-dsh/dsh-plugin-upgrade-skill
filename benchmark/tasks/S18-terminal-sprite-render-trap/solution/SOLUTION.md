# S18 参考解法

## 考点（一句话）

**终端半块精灵渲染的三类视觉缺陷 + 定时器钉死事件循环**：只填充一半的半块格
（▀/▄ 空半区）不重置 SGR 背景——背景跨格持久，把上一格的颜色画进空半区成为幻影
像素（修复：半填充格显式 `ESC[49m` 重置背景）；每行裁掉尾部透明格——窄帧
切换后宽帧残余像素留屏（修复：整行铺满精灵宽度 + 行尾 `ESC[K` 擦除）；手移植
帧数据漂移（excerpt 回归盖不住——修复：全帧 digest 对源画断言）；规划器常驻
setTimeout 链把"只挂不卸"的探针宿主钉死到 CI 超时（修复：`timer.unref()`，
交互终端靠 TTY/stdin 句柄不受影响）；上线前对默认开启的动画特性做探针定时器审计。
