### DSH-0.2.2-R2-01 · Worktree review expands to branch/commit/file-type filters with GitHub review handling, sync of reviewed progress, and branch updates — plugins integrating the change-request surface must re-verify their entry points

- **Type**: capability
- **Applies to**: plugins that integrate the experimental change-request/worktree surface (most plugins do not)
- **Touchpoints**: change-request & worktree entry points
- **Action level**: optional
- **Symptoms**:
  - Reviews can now filter by branch, commit, and file type; GitHub review comments can be handled in-place; reviewed progress syncs and branches update from the review UI.
  - Large-repo worktree creation waits were relaxed; comment and file navigation in code review improved for narrow screens.
  - Plugins that registered their own review or worktree entry points should re-verify them against the expanded surface.
- **Migration recipe**:
  1. No action for plugins that do not touch the change-request surface.
  2. If the plugin extends review or worktree UI, re-run its entry-point smoke on rc.2 and check the new filter and sync behaviors do not collide with its own panels.
- **Verification**: open the change-request entry on rc.2; confirm filters render and a review round-trip completes.
- **Source**: [dsh-v0.2.2-rc.2 release notes](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.2)（"Git Worktree 支持按分支、提交和文件类型审阅改动……同步已审阅进度和更新分支"）.

### DSH-0.2.2-R2-02 · SubAgents grow named and multi-layer collaboration; AgentTeam is per-session with shared member and task panels — subagent-origin sessions carry new lineage data

- **Type**: behavior
- **Applies to**: plugins that list sessions, render subagent state, or read session lineage
- **Touchpoints**: session list rows (origin/parentId/lineage depth), subagent browsing
- **Action level**: informational
- **Symptoms**:
  - Subagents support names and multi-layer (nested) collaboration; AgentTeam opens per session and shares member and task panels.
  - Multi-layer browsing prioritizes task descriptions, expands layer by layer, and retries after read failures.
  - Session-list consumers may see deeper lineage trees; sidebar hiding of subagent rows remains.
- **Migration recipe**:
  1. Plugins counting or grouping subagent rows should tolerate deeper nesting (a descendant chain longer than two).
  2. No API change: the lineage fields (origin, parentId) keep their shape; only depth expectations change.
- **Verification**: spawn a nested subagent on rc.2; confirm the plugin's session-related UI still groups rows correctly.
- **Source**: [dsh-v0.2.2-rc.2 release notes](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.2)（"SubAgent 支持具名与多层协作，AgentTeam 可按会话开启，共用成员与任务面板"）.

### DSH-0.2.2-R2-03 · Custom floating overlays must adapt to the new menu/overlay positioning interface (zoom, pan, long-list alignment); six-plugin fleet verified zero-adaptation on rc.2

- **Type**: behavior
- **Applies to**: plugins rendering custom floating panels or menus
- **Touchpoints**: overlay/menu positioning interface
- **Action level**: conditional
- **Symptoms**:
  - Menus and floating panels stay aligned with their trigger under page zoom, pan, and long lists; custom overlays must adapt to the new positioning interface to keep alignment.
  - Sidebar plugin entries can be tucked into "more" with order preserved on re-pinning (affects plugins whose entry visibility matters).
  - Custom theme coverage extends to notification, card, plan, and task surfaces.
  - First-hand: the six maintained plugins (paste-input 0.2.20, file-trace 0.4.7, input-history 0.1.33, ui-progress 0.11.18, ui-whale 0.3.37, minigames 0.12.4) boot on rc.2 with zero adaptation — only compatibility-ledger rows were added.
- **Migration recipe**:
  1. If the plugin renders its own floating overlay, verify trigger alignment under browser zoom (Ctrl+±) and long lists on rc.2; adapt to the new positioning interface if misaligned.
  2. Otherwise: append the rc.2 row to the compatibility ledger, rebuild, release.
  3. Post-install health check per the runbook: `dsh --version` + one headless round-trip.
- **Verification**: open the plugin's floating UI under 80%/125% zoom and after scrolling a long transcript; position stays anchored.
- **Source**: [dsh-v0.2.2-rc.2 release notes](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.2)（"改善页面缩放、平移及长列表场景下的菜单定位……自定义浮层需适配新定位接口"）; first-hand fleet upgrade 2026-11-13.
