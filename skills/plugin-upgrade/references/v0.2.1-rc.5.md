### DSH-0.2.1-R4-01 · Reasoning Body Slot: `text` becomes display-ready text and the original model output moves to `rawText`

- **Type**: behavior
- **Applies to**: Web client plugins contributing to the `conversation.chat.reasoning.body` slot (custom reasoning renderers, reasoning-translation wrappers) or calling the `conversation.chat.reasoning.content` Content Factory from `@deepseek-ai/dsh-client-ui-chat`; every other plugin only needs a declaration release
- **Touchpoints**: #5 (client slot contribution)
- **Action level**: required-if-hit
- **Symptoms**:
  - `ReasoningBodyOwnerProps` gains `rawText` (the complete or streaming model output); the existing `text` field now carries Chat's prepared display text instead of the original output. `running` is unchanged. A contribution that read `text` as the raw model output now sees processed text — a semantic change with no type error.
  - `ReasoningContentInput` (the Content Factory input) no longer extends `ReasoningBodyOwnerProps`: it takes the caller-selected Markdown `text`, `running`, and optional `labels`, and renders it without repeating Chat's display processing.
  - The release notes list this as one display improvement ("Improve how thinking content is displayed in conversations"). First-hand npm pack diff (2026-10-30): the CLI `lib/` is byte-identical to rc.4 and `dsh-plugin-manager`, `dsh-web-app`, `dsh-web-frontend` differ only in `package.json` version pins — the change ships in `@deepseek-ai/dsh-client-ui-chat`, which that spot-check did not cover.
- **Migration recipe**:
  1. Keep reading `text` for ordinary rendering, translation requests, and untranslated views; switch to `rawText` wherever the full model output is required.
  2. Pass the selected `text` (or its translation) to the Content Factory without re-applying Chat's display processing.
  3. Plugins that do not touch the reasoning slots: add `0.2.1-rc.5` to `compatibility.json` and cut a declaration release.
- **Verification**: rebuild the extension and check streamed and settled reasoning rendering, translation, and the untranslated view for each supported model format.
- **Source**: [reasoning-body-props guide](https://github.com/deepseek-ai/deepseek-harness/blob/dsh-v0.2.1-rc.5/docs/upgrade-guide/v0.2.1-rc.4/reasoning-body-props/guide.md) at `dsh-v0.2.1-rc.5`; [534dac8c8](https://github.com/deepseek-ai/deepseek-harness/commit/534dac8c8) `fix(web): customize thinking block rendering (#7484)` (`packages/client/ui-chat/src/client/contract/slots.ts`); [release `dsh-v0.2.1-rc.5`](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.5); first-hand npm pack diff of [`@deepseek-ai/dsh@0.2.1-rc.5`](https://www.npmjs.com/package/@deepseek-ai/dsh/v/0.2.1-rc.5) and the three spot-checked subpackages.
